| R15 | 平和と対々和、七対子と面子役、一盃口と三暗刻などの不両立を、金額を合わせれば受理した | 最小順子数・刻子数、特殊形、字牌・么九牌・色数・必要順子の条件を公開役から検査。V374–V383。既存の完全手牌fixtureから再計算した全和了も通過 |
| R16 | 既存の槓・責任払いsnapshot例を猶予3,000msのルールで検査すると、個別残18,000msに対して同期限のgroup残が21,000msだった | V292・V293・V324の共通前提を18,000msへ同期。負例は本来の牌・責任履歴の不備を維持し、回帰テストが意図した理由を検査できる状態にした |

R3はJSON Schemaの不具合ではない。`uniqueItems` は配列要素全体の一意性を扱うため、object内のIDだけの一意性には別の制約が必要である。[JSON Schema Validation §6.4.3](https://json-schema.org/draft/2020-12/json-schema-validation#name-uniqueitems)を参照する。

R1–R11は開始時点に存在した修正記録であり、既存の未コミット変更を保持して点検した。今回追加で再現・修正した事項はR12–R16である。認証計画にも、認証成功後に原因eventとgroup時計のcore検査を省略しない受入条件AUTH-09を追記した。

## 検証の範囲

他家の秘密手牌、暗号学的なtoken生成、実サービスの認証、異なる実装間の相互運用性は、このリポジトリのテストだけでは保証できない。形式モデルの結果にも有限境界と環境仮定がある。[検証ガイド](../verification/README.md)と[形式モデルの説明](../verification/quint/README.md)に従う。

今回追加したsnapshotの原因・時計式・役の不両立はPythonの受信・採点検査で確認した。Quintは既存の抽象モデルの範囲を再検査しており、これらの具体的なpayload検査を新たに形式証明したとは扱わない。

HTMLは参考文書を含む閲覧用成果物であり、規範本文の原本はMarkdownである。認証・認可計画と本レビューはMDXを原本とする。
