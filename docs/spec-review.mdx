## 検証の限界

今回の修正は、Pythonによる受信・交渉・公開採点契約の検査で確認する。Quintの5モデルは既存の有限抽象モデルであり、新しいpayload条件そのものの形式証明や実装とのrefinement証明ではない。詳細は[検証ガイド](../verification/README.md)と[形式モデルの説明](../verification/quint/README.md)に従う。

非公開手牌が必要な役の完全判定、ホストの牌山生成、暗号学的token生成、実サービスの認証、独立実装間の相互運用性は、このリポジトリの受信テストだけでは保証できない。認証計画の受入条件は未実装のためtodoとしている。HTMLはMarkdown・MDXから生成する閲覧用成果物である。
